# Backend para Gestión de Proyectos Universitarios - UdeA 🎓💻

Este repositorio contiene el backend desarrollado para gestionar los proyectos académicos y de investigación de la Universidad de Antioquia (UdeA). Proporciona una API basada en **GraphQL** para interactuar con una base de datos **MongoDB**, permitiendo a los usuarios administrar proyectos, roles, estados y otros datos relacionados.

---

## Características principales 🚀

- **Gestión de proyectos**:
  - Crear, leer, actualizar y eliminar información de proyectos.
  - Seguimiento del estado de los proyectos (activo, en desarrollo, finalizado).
  
- **Gestión de usuarios**:
  - Registro de estudiantes, profesores y administradores.
  - Asignación de roles y permisos.
  
- **Conexión con MongoDB**:
  - Almacenamiento de información de proyectos y usuarios en una base de datos no relacional.
  
- **API GraphQL**:
  - Consultas y mutaciones para interactuar con los datos de manera eficiente.
  - Soporte para esquemas y resolvers personalizados.

---

## Tecnologías utilizadas 🛠️

- **Lenguaje principal**: JavaScript (Node.js)
- **Base de datos**: MongoDB
- **API**: GraphQL
- **Servidor**: Express.js
- **Autenticación**: JSON Web Tokens (JWT)

---

## Requisitos del Proyecto 📋

1. **Node.js**: Versión 16.x o superior.
2. **MongoDB**: Instancia local o en la nube (e.g., MongoDB Atlas).
